# VDO Cntrl

Developed by DhaxArts.

Control multicámara para OBS con VDO.Ninja, cámara local opcional y controles de escena adaptados al tema y al tamaño del dock.

## Descargar

Abre [la última versión](https://github.com/dhaxarts/VDO-Cntrl/releases/latest).

- **VDO-Cntrl-Setup.exe**: instalador completo para un equipo con OBS compatible ya instalado.
- **VDO-Cntrl-Actualizacion.zip**: actualización acumulativa para instalaciones existentes.

Cierra OBS antes de instalar o actualizar. Para actualizar manualmente, extrae el ZIP completo y ejecuta **ACTUALIZAR.cmd**. Se hace una copia de seguridad y se conservan tus ajustes, salas y cámaras.

## Actualizaciones automáticas

En Configuración > Actualizaciones puedes activar la búsqueda y la descarga en segundo plano. Las nuevas versiones firmadas se instalan al cerrar OBS. Windows puede pedir autorización para sustituir una DLL protegida.

No necesitas una cuenta ni un token de GitHub para recibir actualizaciones. Las firmas Ed25519 y los hashes se verifican antes de instalar. Los descriptores y firmas adjuntos son archivos del actualizador: para instalar manualmente solo necesitas el instalador o el ZIP.

Requiere OBS x64 31.1–32.x ya instalado. No instala ni actualiza OBS.
