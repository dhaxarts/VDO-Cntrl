# VDO Cntrl

Developed by DhaxArts.

Control multicámara para OBS con VDO.Ninja, cámara local opcional, escenas de reacción y layouts de mesa.

## Descargar

Abre [la última versión](https://github.com/dhaxarts/VDO-Cntrl/releases/latest).

- **VDO-Cntrl-Setup.exe**: instalador completo para un equipo con OBS compatible ya instalado.
- **VDO-Cntrl-Actualizacion.zip**: actualización acumulativa para instalaciones existentes.

Para actualizar manualmente, cierra OBS, extrae el ZIP completo y ejecuta **ACTUALIZAR.cmd**. Se hace una copia de seguridad y se conservan tus ajustes, salas y cámaras. La versión 2026.10.17 incorpora el nombre VDO Cntrl y migra el dock anterior sin duplicarlo.

## Actualizaciones automáticas

En Configuración > Actualizaciones puedes activar la búsqueda y la descarga en segundo plano. Las nuevas versiones firmadas se instalan al cerrar OBS. Windows puede pedir autorización para sustituir una DLL protegida. Los usuarios sin el mecanismo automático deben instalar una primera actualización manual.

No necesitas una cuenta ni un token de GitHub para recibir actualizaciones. Las firmas Ed25519 y los hashes se verifican antes de instalar. Los descriptores y firmas adjuntos a las releases son archivos del actualizador; solo necesitas descargar el instalador o el ZIP para instalar manualmente.

Requiere OBS x64 31.1–32.x ya instalado. No instala ni actualiza OBS. Se conservan los identificadores internos necesarios para mantener la compatibilidad con instalaciones anteriores.
